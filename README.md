# Kipphard Wishlist for WooCommerce

A fast, persistent wishlist for WooCommerce — heart button on products, works for guests and logged-in users, rendered via the `[kipphard_wishlist]` shortcode in your theme's style.

## ▶ Live demo (no install)

**[Open the demo in WordPress Playground](https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/kipphard/kipphard-wishlist/main/demo/blueprint.json)**
— a full WordPress with the plugin installed and demo content seeded, running entirely in your browser.

## Install

Download the latest [release](https://github.com/kipphard/kipphard-wishlist/releases) zip
→ WordPress admin → *Plugins → Add New → Upload Plugin → Activate*.

## Features (free)

- Heart button on product cards + product pages
- Persistent for guests (cookie) and users (custom table)
- `[kipphard_wishlist]` page: grid, list, or table layout (kip-ui)
- Add-to-cart straight from the wishlist
