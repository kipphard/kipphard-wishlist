# Wunschliste — Wishlist for WooCommerce

A fast, clean WooCommerce **wishlist**. Customers click a heart to save products for later;
the list persists — in the account for logged-in users, via a cookie for guests. A
`[wunschliste]` page shows saved items with add-to-cart. More return visits, more conversions.

## ▶ Live demo (no install)

**[Open the demo in WordPress Playground](https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/kipphard/wunschliste/main/demo/blueprint.json)**
— a WooCommerce shop with the wishlist heart button, in your browser.

## Install

Requires **WooCommerce**. Download the latest
[release](https://github.com/kipphard/wunschliste/releases) zip → WordPress admin →
*Plugins → Add New → Upload Plugin → Activate*.

## Features (free)

- Heart "add to wishlist" button on shop + product pages (AJAX, no reload)
- Persistent wishlist for **guests (cookie)** and **logged-in customers (account)**
- `[wunschliste]` page with saved products + add-to-cart
- Bilingual (German + English)
